# DPI LTM CubeSat — working notes

Mission website + analyses for a 1U PROVES Kit CubeSat flying the AMSAT Linear Transponder Module (LTM-1).
Built 2026-10-25.

## Layout

| Path | What |
|---|---|
| `build.py` | Generates the whole site into `public/` from the analysis modules |
| `analysis/orbit.py` | Circular-orbit helpers (period, eclipse, SSO inclination, slant range, passes) |
| `analysis/power_budget.py` | Solar generation, loads per mode, SoC simulation, transponder duty |
| `analysis/link_budget.py` | Telemetry / transponder / command link margins, Doppler |
| `analysis/orbit_lifetime.py` | Decay model calibrated to PROVES DAS runs; FCC 5-yr / NASA 25-yr |
| `analysis/mass_budget.py` | Mass budget (from PROVES Atlas DAS component list + LTM) |
| `analysis/das_inputs.py` | Writes a NASA DAS 3.2 project folder (`public/das_project/`) |
| `web/` | `styles.css`, `charts.js` (dependency-free SVG charts with hover + data tables) |
| `web/mockup.js`, `web/vendor/` | 3D mockup (three.js 0.170, MIT, vendored); `mockup.html?explode=1&panels=0&view=inside` presets |
| `web/chat.js` | Chat widget (floating on every page, inline on `ask.html`); safe minimal Markdown renderer |
| `chat/handler.py` | Chatbot Lambda: Claude Opus 5.5 on Bedrock (Mantle), research tools, rate limits |
| `chat/knowledge.md` | Generated by `build.py` from the built pages; the chatbot's system-prompt knowledge base |
| `deploy/deploy_chat.sh` | Packages + deploys the chatbot (Lambda, function URL, DynamoDB table, IAM role) |
| `deploy/deploy.sh` | Builds, syncs to private S3, CloudFront (OAC, HTTPS). `deploy/state.env` holds resource IDs |

Rebuild: `python3 build.py`. Redeploy: `./deploy/deploy.sh` (re-sync + invalidation).

## Chatbot ("Ask AI")

- Lambda `dpi-ltm-chat` (python3.13, 1 GB, 120 s timeout, reserved concurrency 5), role `dpi-ltm-chat-lambda`
  (Bedrock/Mantle invoke + UpdateItem on the rate table only). Function URL is public (auth NONE) with CORS and an
  Origin check limited to the CloudFront site; URL recorded in `deploy/chat_state.env` and baked into pages by `build.py`.
- Model `anthropic.claude-opus-5-5` via `AnthropicBedrockMantle`, effort `medium`; client-side refusal fallback
  (`BetaRefusalFallbackMiddleware`) to `anthropic.claude-opus-4-8`. System prompt (~10K tokens incl. knowledge base) is cached.
- Research tools are client-side because Bedrock has no server web search/fetch (verified: 400 "not supported").
  `fetch_page` (HTTPS, domain allowlist, public-IP check, redirects re-checked), `github_repo`, `github_search_repos`
  (unauthenticated GitHub API, 60 req/h per Lambda IP), `wikipedia_search`. Max 8 tool rounds / ~100 s per question.
- Limits: 20 questions/hour/IP and 400/day global (DynamoDB `dpi-ltm-chat-ratelimit`, TTL). Tune via env vars in
  `deploy_chat.sh`. Rough cost: a few cents per question (cached system prompt; research questions cost more).
- Guardrail: the system prompt forbids reproducing AMSAT ICD content (tested: declines CAN IDs / pinouts).
- Redeploy after site content changes: `./deploy/deploy_chat.sh` (re-generates knowledge.md) then `./deploy/deploy.sh`.
  Both need the venv on PATH: `PATH=$PWD/.venv/bin:$PATH` (anthropic[bedrock], boto3, numpy).

## Sources

- The working directory was empty at start (no local LTM docs), so LTM facts come from the **public**
  AMSAT page https://www.amsat.org/amsat-linear-transponder-module/:
  V/u, 30 kHz passband, SSB/CW; TX 100 mW TLM / 450 mW TLM+transponder; 1200 bps BPSK (FoxTelem);
  5–7 V, 40 mA safe, 310 mA @ ~11 % duty telemetry, 300–650 mA transponder; 92×90×33 mm, 130 g; PC-104; CAN; boards (bottom→top): transponder, ICR command receiver, LTI host interface (LIHU fills the LTI slot on AMSAT's own Fox-Plus/GOLF-TEE); heritage HO-107, AO-109, MO-122.
- FC: github.com/dpiresearch/claude_flight_board (FC_V5d_LTM_mods_20261010). Its README says the LTM interface
  notes derive from AMSAT's *proprietary* Generic ICD / ATP. **The site deliberately does not reproduce ICD
  details** (CAN IDs/addressing, pinouts, message formats); it links to the repo and summarizes only.
- Battery pack v2: 4× 18650 2S2P (cell P/N not in BOM; NCR18650B 3D model). EPS lives on the FC: LT3652
  (float 8.38 V, 1 A, VIN-reg 8.44 V), TPS54226 3.3 V, TPS54225 5 V LTM_VSYS (off at boot; GPB6 enable; USB force-on).
- Solar XY_Faces_V2a: 6× KXOB101K08TF per face, 2s3p (schematic value says SM101K07TF — mismatch).
- Antenna top cap v2c: tape-measure elements + burn wire (DAS file: 2 × 0.1778 m elements ⇒ 70 cm).
- "DAS software" interpreted as NASA **Debris Assessment Software**; reference inputs/outputs from
  github.com/proveskit/The-PROVES-Project-DAS (Atlas, Electra, Maia, Taygeta — DAS 3.x runs, Sep 2025).

## Key results (baseline 525 km SSO, Nov 2027)

- Mass: 1.20 kg CBE, 1.26 kg MEV (limit 2.0 kg).
- Power: 1.64 W/face AM0; tumbling 5-face mean 2.05 W; η 0.61 ⇒ 1.25 W sunlit, **0.78 W orbit-avg** (β=0, EOL).
  Beacon mode 0.68 W (sustainable). Transponder 2.86 W typ / 3.84 W max ⇒ **max ~4.8 % duty (~70 min/day)** at β=0,
  ~8 % at β=45°, ~26 % in full sun. Battery 38.6 Wh EOL, eclipse DoD < 6 %.
- Link (10° el): fixed station closes everything (+6 dB SSB end-to-end, telemetry +11 dB at 10°). Portable Yagi is
  marginal below ~25–30° (telemetry −0.4 dB, SSB −3.9 dB at 10°). Doppler ±10.2 kHz down / ±3.4 kHz up.
- Lifetime: model calibrated (density × 0.439) to 4 PROVES DAS runs (all within 1 %). 525 km ⇒ ~6.9 yr
  (1.7–14 yr solar max/min bounds). NASA 25-yr OK; **FCC 5-yr requires ≲ 475 km** drop-off or a drag device.

## Open items / risks flagged on the site

1. No 2 m (uplink) antenna on the PROVES top cap — LTM needs a V-band element or diplexed solution.
2. LT3652 operating point vs 2S panel Vmp/Voc — bench test (10 % loss carried).
3. FC V5d LTM board unrouted (87 ratsnest); J30–LTM harness not designed.
4. AMSAT ICD confirmations (CAN termination, MAX31725 address, UTC year encoding) — per FC README.
5. Part-number mismatches (solar cell, battery protector) in source repos.
6. FCC 5-year rule vs Transporter altitude — needs launch-provider answer before ODAR.
7. Frequencies on the site are representative (Fox-1E plan) pending IARU coordination.
8. Ground-station gains are typical values, not vendor-verified; LTM currents to be measured on FlatSat.

## Caveats on the models

- Lifetime calibration points are all ~417 km near solar max; 500–600 km through solar min is extrapolation.
  Run DAS 3.2.7 on `public/das_project/` for authoritative numbers.
- Solar cell Pmp (0.20 W AM1.5) is datasheet-typical, not verified against the KXOB101K08TF datasheet.
- LTM "beacon" average interprets AMSAT's "310 mA @ ~11 % duty" as TX current × duty over a 40 mA baseline.
