Website and analysis source

Analysis code

  • analysis/power_budget.py: solar generation, mode loads, state-of-charge simulation
  • analysis/link_budget.py: downlink, uplink and end-to-end transponder margins, Doppler
  • analysis/orbit_lifetime.py: DAS-calibrated decay model
  • analysis/mass_budget.py, analysis/das_inputs.py: mass budget and DAS project generator
  • build.py: generates this site
DPI Research · AMSAT · Arrow Technologies of Texas — a PROVES Kit 1U CubeSat carrying the AMSAT Linear Transponder Module. Analyses are engineering estimates for planning; see each page for assumptions. Site source: https://github.com/dpiresearch/sat_mission_20261025.
